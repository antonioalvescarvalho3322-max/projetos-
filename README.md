## Como adicionar um novo projeto em destaque

Copie um bloco `<article class="project-card">` em `index.html`, troque o título,
a descrição, as tags e o link.

## Como publicar no GitHub Pages

1. No repositório, vá em **Settings → Pages**.
2. Em **Source**, escolha a branch (ex.: `main`) e a pasta `/ (root)`.
3. Salve. O site ficará disponível em
   `https://antonioalvescarvalho3322-max.github.io/projetos-/`.
